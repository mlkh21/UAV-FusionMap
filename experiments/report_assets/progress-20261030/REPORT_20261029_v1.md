# 高速固定翼无人机感知与地图工程进展报告

报告日期：2026-10-29；版本：v1；主责任：Technical Lead；状态：已完成（仓内报告稿）。
项目：UAV-FusionMap；计划周期：2026年9月—2027年3月。
本文整理已有实现及运行证据，尚未对外发布。

## 1. 当前工程结果

项目已经形成可不依赖研究模型运行的仿真状态、Radar/IR接口、占位感知、地图查询、
公开收据回放和原生可视化软件链。M2概率、M3区间质量、M4场景地图、M5独立地形
完成各自合成软件工作包及ROS交接，组合测试覆盖失效、时间、未知区域、版本和恢复。
当前关闭的是这些软件范围；真实Radar–IR融合质量、机载性能与正式阶段验收仍待完成。

```mermaid
flowchart LR
    S[仿真状态与功能级场景] --> R[Radar / IR及状态适配]
    R --> P[占位感知 / 研究后端不可用出口]
    P --> M[占据地图与公开查询]
    M --> A[应用查询 / 原生RViz]
    T[独立合成地形先验] --> Q[地形查询 / 独立RViz]
```

地图累计配置与占位链分开：M2—M4使用声明的合成逆观测，不能直接把占位后验累计。
地形高度单独保留来源、基准、时间、版本与质量，没有参与占据融合。
LiDAR只允许训练监督分支，未进入在线SensorBundle、定位、mapping或模型forward。

## 2. 场景与传感器查看

下列四图来自同一次原生Gazebo/RViz会话；飞机固定于声明安装位姿。
可见几何与采样几何同源，Radar是几何采样代理，IR是热材质强度代理。

![图1 Gazebo功能级场景](../experiments/report_assets/p5-delivery-20261029/gazebo-scene.png)

图1：固定翼外观、墙体、冷柱、暖柱与热箱构成独立功能级场景，未连接PX4/JSBSim飞行。

![图2 RViz点云、IR与占位地图](../experiments/report_assets/p5-delivery-20261029/radar-ir-map.png)

图2：标准RViz同时显示Radar点云、IR投影及Radar驱动的占位地图。
本次检查点包含1790个回波与594个占据cell；这些数量不表示重建精度或模型质量。

![图3 Radar与地图视口](../experiments/report_assets/p5-delivery-20261029/radar-map-viewport.png)

图3：彩色回波按高度着色，体素表示占位占据，过期历史按视图规则显示。
未观测空间保持未知，无回波不生成自由空间证据。

![图4 IR热强度代理](../experiments/report_assets/p5-delivery-20261029/ir-viewport.png)

图4：冷、暖、热材质及遮挡形成IR投影，强度单位是fixture_intensity，不是温度。
同次验收将热箱沿y移动1.5m，改变14779个IR像素及408个Radar点，并在结束后恢复原位。
这验证场景变化会传递到两个传感器，未验证飞行动力学或真实传感器物理精度。

## 4. 软件验证结果

| 验证对象 | 已有实际证据 | 能说明什么 |
| --- | --- | --- |
| A/B组合ROS | 33独立子例；148占据、143快照、14查询执行地图回放 | 公开接口、失效、累计与时间/质量保真 |
| S09/C及交接 | 四个图故障/恢复/原生子例；全矩阵合计37例、253事件、95检查点、228项比较 | 图拒绝、自有进程清理、新run不继承旧地图/pin与原生显示 |
| 轻量回归 | 上一轮全仓819/819、P5定向45/45；742次实际生成消息往返 | 对应已有代码的单元/契约回归，不等于819个真实场景 |
| 地形记录 | 独立窗口会话22事件/8查询完整执行回放；S08不完整与篡改分别拒绝 | 合成公共记录可复现，v1不能表达的故障保持incomplete |
| 原生渲染与清理 | 场景/Radar/IR及地形四状态像素通过；宿主36个受管命令无残留 | 软件渲染目标有效、该次运行已退出；非持续部署保证 |

A/B与C分别来自两次具名运行，交接时核对源码与冻结合同并重比收据；没有37例在同一
新会话全部重跑。两次初始S09验收设施失败、修复与最终运行均保留，未改冻结预期掩盖失败。
本轮为报告整理与设计审计，只读复核上述结果、运行相关既有定向及地形离线回放，
没有重新执行全仓819项或启动ROS/GUI/模型。
