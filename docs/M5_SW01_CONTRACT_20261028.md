## 1. 入口与范围

[m5_contract.py](../mapping/ufm_mapping/m5_contract.py)只提供无状态检查：

- `validate_spec(spec)`：验证已解码的私有输入，成功返回None，非法抛ValueError，不修改输入。
- `load_fixture(path)`：最多读取16KiB+1，超限先拒绝，再按UTF-8 JSON解析和validate_spec；
  拒绝重复key、NaN/Infinity及非法编码/过深结构，不安装或导入GIS库。
- `validate_request(spec, request)`：只检查请求字段、map/run/clock、有限中心格点和非负int64时间，
  不查询高程、不返回valid/stale等地形结果；查询时段/安装水位与有效性判断留给候选。

这是mapping内部fixture合同，不是公共TerrainPrior消息或已接入的地形层。
`factory.create_map('m5_fixture')`仍明确拒绝，默认latest及M2/M3/M4不导入新模块或读取地形文件。
不改SensorBundle、OccupancyObservation、MapSnapshot、MapQuery或应用显示，不启ROS/Gazebo。

复现冻结和检查：


未来安装/查询事件载荷及报告，不覆盖旧run。YAML配置只由测试fixture构建器读取，
mapping私有文件入口固定JSON，不自动猜测格式或读取source_ref指向的数据。

## 2. 冻结编码与单位

以[配置](../configs/m5_terrain_fixture.yaml)为最小实例，schema固定`m5_terrain_fixture.v1`。
所有结构字段严格匹配，缺失/额外字段拒绝；训练用lidar/target/observed_mask不在任何输入边界允许集内。
数字不接受布尔值/字符串或非有限数，时间为非负int64 ns。数组固定JSON list，行优先索引`r*columns+c`。

| 组 | 冻结语义 |
| --- | --- |
| identity | terrain_id/dataset_version/tile_id/source_ref为非空文字；source_kind=fixture、product_kind=DTM；DSM/未知产品与真实来源暂不支持 |
| source_time | acquisition_ns/publication_ns/precision_ns、dataset_epoch与独立dataset:m5-fixture时钟；precision>0、发布不早于采集。首版不支持未知采集时间或真实UTC数据 |
| horizontal | fixture:terrain_xy_v1、terrain_fixture、[x,y]、m，明确为合成源水平参考 |
| vertical | fixture:terrain_height_zero_v1、local_height、m；operation=fixed_translation_fixture_v1、required_grids=[]；不接受椭球/正高或省略必须网格的转换 |
| grid | rows/columns、row-major heights/no_data_mask/height_quality、affine、sample_anchor=center；north-up且无旋转/剪切 |
| map_grid | fixture:map_xy_v1、fixture:map_height_zero_v1、map、m；origin_xy/resolution_xy，源/目标基准分别具名 |
| registration | 具名terrain_fixture→map固定非零平移、fixture来源/available、run/clock、左闭右开有效时段、精确合成水平对齐及独立垂直平移质量 |
| eligibility | fixture_run_authorization_v1、与注册一致的run/clock和显式时段；全部包含于注册有效期；不将dataset时钟与sim时钟相减 |
| limits | 1 tile、每轴≤4、每tile/总计≤16样本、文件≤16384B、未来收据≤64事件；首版不允许修改这些固定上界 |

几何：affine=[100,2,0,200,0,-2]，首中心为[101,199]，第二行首中心为[101,197]。
T_map_terrain的平移为[10,-20,3]，map网格原点xy=[110,176]、分辨率[2,2]。
源角点+平移与map格点必须整格对齐，只允许同分辨率；非中心请求/需要插值的位置拒绝。
覆盖外但仍位于合法中心格点的请求可通过语法检查，是否unknown由后续候选返回。

no_data_mask=true必须height=null且质量unavailable，不能将0、负数、空数组或数值1/0当作缺失。
mask=false时高度必须有限；有效高度允许质量unavailable，保留缺失原因，不能默认零误差。
每样本`height_interval/m`是**源绝对高程区间**并包含其名义height；不是概率、误差半径或方差。
注册的`height_offset_interval/m`是**z平移本身的区间**并包含名义tz；不是点高度，也不是零中心的平移误差。
例如height=10、源界[9.75,10.25]、tz=3且tz界[2.9,3.1]，保存的map高度预期为13、界[12.65,13.35]。
这些map结果仅由独立表/有理数算例核对，本轮没有候选执行结果。

文件字节限额由load_fixture在解码前执行；直接调用validate_spec的调用者已经持有对象，
该方法只检查结构/样本上界，不能倒推或撤销调用者此前分配。64事件是后续候选/收据的冻结上限，
本轮没有事件缓存、去重历史、安装事务或临时峰值测量；不声称RSS、速度或机载资源达标。
