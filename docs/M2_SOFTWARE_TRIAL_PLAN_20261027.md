## 3. 唯一首版候选：有界log-odds

本节是首版候选规格，不声称合成值是物理测量似然或真实模型的已校准输出。
观测序列由测试显式构造，占据与free分别有独立样本身份，计算oracle提前给定。
实际设备的相关性、重复视野及模型分数校准均留待真实证据模型评审。

定义`logit(p)=ln(p/(1-p))`、先验`p0=0.5`、`L0=0`。
合格逆观测概率为`p_z`，单次增量`d=logit(p_z)-logit(p0)`；
累积`L_new=clip(L_old+d,L_min,L_max)`，输出`p=1/(1+exp(-L_new))`。

第一组数值fixture固定`p_occ=0.75`、`p_free=0.25`、
`L_min=-ln(9)`、`L_max=ln(9)`，因此输出限于[0.1,0.9]。
这些值仅用于算术验收，不替换现有PERF-01或飞行质量参数。
输入概率须在(0,1)且有限；0/1与非法值拒绝整帧，不静默epsilon修补。

| 合成输入 | 预期概率/语义 |
| --- | --- |
| 单次occupied 0.75 | 0.75，1次有效证据 |
| 再一次独立身份的occupied 0.75 | 0.9，达到fixture上限 |
| 接着三次free 0.25 | 依次0.75、0.5、0.25；冲突不会被永久锁成occupied |
| occupied 0.75之后free 0.25 | 0.5且observed=true；已观测冲突域为unknown，不能当作从未观测 |
| observed=false、体素未列出、无回波或N=0 | 不贡献自由/占据证据，不更新旧cell的最后证据时间 |
| 显式p_z=0.5 | 中性输入，不改变旧证据/时间，不创建新的可融合cell；与历史正负证据抵消为0.5区分 |

clipping使不同时间序列不必具有交换/结合性。必须按严格事件时间顺序逐帧累计，
不得先把一批增量求和后仅裁剪一次，再宣称与逐帧结果等价。
当前研究Occupancy预测概率可能已经是后验且多帧相关，不能直接代入本式；
`source_type=model/measured/simulation`或非候选观测域在首版试制一律拒绝。

## 4. 输入、身份与原子性

只消费现有OccupancyObservation和随附SpatialContext；不读SensorBundle、Radar/IR、
LiDAR、target或训练observed_mask。这里的`voxel.observed`仍是在线公开占据合同，
不是训练监督掩码。free必须来自上述明确合成free观测，不能从点云稀疏或未命中推导。

沿用现有schema/frame/网格、刚体变换、有限概率及Quality合法性检查；输入整帧校验成功后
才改变cell、窗口、revision或时序状态。同帧重复index拒绝，不能给同一体素累计两次。
错run/clock、坏变换、非法体素、来源不合格时，旧概率、时间、窗口和revision均保持不变。

同run同sample_id同内容重投递不重复累计；同ID不同内容在有界记录内拒绝。
所有时间不大于最近已接受输入水位的旧帧，均拒绝而不重排；同一时间不同ID也不累计。
来源可信且合同合法的unavailable/degraded消息可推进输入水位，但不推进证据时间。
坏消息不得通过推进水位阻止后续合法恢复。

身份记录建议沿用已验证的有界账本思路，fixture限额1000条并拒绝水位及更早帧；
不承诺识别记录淘汰后“旧ID被改写为未来时间”的全部冲突。生产者必须维持run内身份唯一，
不得用无限ID集合或无消费者的哈希实现伪完整去重。新run创建新地图，绝不自动续接。

## 5. 老化、未知与滚动

首版采用TTL失效，暂不引入连续概率衰减。每cell保留真正贡献证据的
`last_observed_timestamp`；查询、快照重发、unavailable、中性输入不刷新该时间。
候选固定`evidence_ttl_ns`；查询有效年龄为`min(request.max_age_ns,evidence_ttl_ns)`，
严格大于才stale，等于仍新鲜。客户端不能借很大的max_age重新激活超过候选TTL的证据。
该规则只用于显式M2候选，M1现有查询仍保持原合同和结果。

stale查询保留历史概率/时间及observed=true，status为stale；不把老化输出成free，
也不把查询读操作当作概率更新。TTL之后第一次非中性新证据到达时，
先将该cell累积值重置到L0，再加本次增量；历史证据不与新周期继续累乘。
例如TTL=100ms、最后贡献时刻100ms：200ms仍新鲜，201ms为stale，
250ms新的0.75证据应从先验得到0.75；仅有中性/失效消息则保持旧证据stale。

未观测与移入区域保持unknown；有正负历史抵消后的0.5保持observed=true和unknown。
若仅合法空帧引起窗口移动，允许revision表示覆盖变化，但不得推进地图证据时间或旧cell时间；
缺失有效位姿/变换的帧不移动窗口。没有任何有效证据的地图仍是unavailable。

滚动仍按观测时刻body位置整格移动、轴向固定odom；重叠cell携带L及原证据时间，
移出cell整体丢弃，不能在移入位置复用旧累积值。先固定网格验收，再接滚动。
SW-03已实现独立`RollingProbabilityMap`：只在滚动候选接受显式有效刚体body位姿和
与配置同格点的odom观测origin，source变换仍须声明单位阵；不旋转odom网格。
非valid消息可声明变换unavailable，此时不读取占位矩阵、不移动窗口且不得携带体素。
窗口移动时间在内部单独记录；查询早于最新覆盖变化时返回unavailable，
避免以最新窗口回答过去的查询。快照header.timestamp仍保留最新实际贡献证据的时间。
活跃cell上限沿用具名fixture配置10000；满容量按最后证据时间及确定性索引顺序淘汰，
相同输入回放结果必须一致。此为数据结构限额，不证明目标机RSS/功耗或实时性。

## 6. 输出、兼容与恢复

沿用现有MapSnapshot/MapQueryResult字段和五类查询状态；probability表达本候选的
合成累积结果，last_observed_timestamp为真实贡献时刻，source_types保留fixture。
没有校准证据时confidence=None、uncertainty=unavailable；不把观测次数、
输入confidence、熵或`p*(1-p)`伪装成校准融合质量，不提前实施M3。
只有显式配置的分类阈值参与occupied/free判定，缺失阈值或中间概率返回unknown。

已新增独立候选类/fixture配置；仅共用需要的地图校验/格点辅助，不重写M1核心。
不采用“先调用M1覆盖更新、再回改私有cell”的拼接方式。
SW-04已增加默认`latest`的节点私有`map_backend`选择，由独立fixture runner显式选择
`m2_fixture`，使用独立map_id和新run，必须提供配置路径及clock_id。
配置缺失、未知后端或M2参数混入latest均明确失败；候选不接受分散覆盖参数。
ROS与回放共用创建逻辑，默认latest不导入M2模块；旧launch不自动启用候选。
应用仍只调用公开查询，不读取L、身份账本或模型。原latest的所有历史收据按原语义回归。

无新增公共ROS字段的需求。如实现发现需要新增累计次数、证据身份或概率语义字段，
应先给生产者、消费者、兼容与恢复方案并另行确认；不能将其夹带进试制。
恢复采用停止候选、新run重启latest；不得将M2累积cell装入M1旧缓存继续融合。
